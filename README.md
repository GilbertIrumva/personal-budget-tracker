# Personal Budget & Expense Tracker

## Project Description

The Personal Budget & Expense Tracker is a simple web page
designed to demonstrate HTML structure, forms, tables,
multimedia elements, and CSS styling.

This project extends the Week 1 Budget Tracker assignment.

## Project Files

### 1. index.html

The HTML file defines the structure and content of the website.

It includes:
- A page header with a logo and title.
- A form for entering an expense name, amount, and category.
- A category dropdown with five expense categories.
- An expense table containing five sample records.
- A collapsible section explaining how to use the tracker.
- An embedded YouTube video.
- A footer with copyright information.

### 2. style.css

The CSS file controls the appearance of the website.

It includes:
- Page and section styling.
- Form input and button styling.
- Table borders and cell spacing.
- A colored table header and alternating row colors.
- Hover effects for table rows.
- Focus effects for form inputs.
- Advanced CSS selectors.
- Responsive styling for smaller screens.

### 3. README.md

This file explains the purpose of the project and the role
of each file.

## Technologies Used

- HTML5
- CSS3

## Current Functionality

The form and dropdown are displayed on the page, and users
can explore the example expenses in the table.

The Add Expense button is not yet connected to JavaScript.
It is included as required by the assignment.

## How to Run the Project

1. Download or clone the GitHub repository.
2. Open the project folder.
3. Open index.html in a web browser.
4. Make sure the computer is connected to the internet
   to load the logo and embedded YouTube video.
